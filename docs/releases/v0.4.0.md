Portable setting profiles, a refreshed native launcher and easier installation. Profile support is based on a contribution by **Markus Stahl**.

### Changes

- **Profiles:** Save your rendering setup, load it with a click and share `.lmuqv` files. Rename, delete, export or import multiple profiles. Importing keeps your game/provider paths, joystick bindings, diagnostics, benchmark placement and headset calibration.
- **Launcher:** An OpenGrid XR inspired dark violet design, softer cards and clearer navigation, using the existing small Windows launcher.
- **Installer and portable:** Choose the setup EXE for Start menu and uninstall integration, or extract the complete portable ZIP. Updates retain your settings and profiles.
- **Updates:** The launcher checks stable GitHub releases and offers an installer download. Installation follows your approval, verifies the checksum and publisher, and requires LMU to be closed.
- **CPU overhead:** Avoid redundant checks on retained outer-bank interfaces and stop rendering/publishing hidden benchmark bitmaps. Add profiler buckets for lock contention. Game frametime gains still need matched testing; SPS/MVR is not enabled in this release.
- **Startup diagnosis:** Check installed signatures, hashes and activation from Setup. This helps investigate EAC errors; it cannot establish EAC approval for an intact signed DLL.

### Updating

Close LMU and the old launcher. Install the setup EXE or extract the complete ZIP into a writable folder. For an existing portable setup, copy `launcher-settings.xml` and your `profiles` folder into the new package. Open the new launcher, save your settings and run **Setup > Install / update automatic startup** to use the updated package with Steam.

Shared profiles never contain your local paths or devices. Portable profiles live beside the launcher in `profiles`. Use **Setup** to remove automatic startup before uninstalling an installed package that owns it.
