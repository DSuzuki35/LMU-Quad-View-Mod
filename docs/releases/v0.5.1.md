Development notes for 0.5.1 — not yet released.

Thank you to **Markus Stahl** for the performance improvements, SimHub integration,
stability fixes and continued help with LMU Quad View. This version integrates
both his 0.5.0 and 0.5.1 patches.

- Experimental SimHub telemetry and benchmark button actions.
- Lower pointer-validation, logging and per-frame allocation overhead.
- Profiler buffers allocated on demand and released when disabled.
- OpenXR input validation, launcher error handling and update cleanup.
- Benchmark shared-memory, overlay, installer and report hardening.

In-game performance gains from these changes have not yet been benchmarked.
Quad Views still needs sufficient CPU headroom; see the 0.4.0 guidance.
