# Stereo VRS 0.2.0 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans with independent
> launcher and gaze-helper tasks dispatched via dispatching-parallel-agents.

**Goal:** Package 0.2.0 with all 0.1.2 features and experimental stereo VRS.
**Architecture:** Native stereo XR passthrough, bounded NVAPI world-sort scopes,
per-eye foveation map and optional isolated gaze input. Quad stays unchanged.
**Tech Stack:** C++17, D3D11/NVAPI, OpenXR, .NET Framework WinForms.
**Spec:** ../specs/2026-11-02-vrs-020-design.md

## Global constraints
- No unfinished SPS branch integration, original eye draws retained.
- No measured performance claims without matched valid hardware captures.
- No global runtime/registry/profile changes for VRS.
- Existing quad settings/features remain available.

## Review focus
- Invalid/stale gaze and asymmetric FOV must select bounded fixed focus.
- NVAPI failure and excluded render scopes must not leak shading state.
- App action sets and XR submission poses must remain intact.
- Old settings and unrelated child environment must not select experiments.
- Benchmark mode labels and no-focus metrics must reflect two-view rendering.
