Measurements

Use “Measure color error” or “Measure GPU paths”.

Color error uses a four-sample-per-pixel reference in linear RGB. It is not a perceptual score. GPU queries include reconstruction/composition, exclude display/readback, and identify the actual renderer. Budget matching counts scene samples, not total GPU work.

What this proves—and what it doesn’t

The inverse map selects each scene ray before shading, so fewer source pixels mean fewer scene evaluations. Reconstructing adds a full output pass. The rectangle-preserving asinh map is nonlinear, not strictly conformal; inspect its diagonal density transitions.

The ray-scene path bypasses curved-triangle rasterization. Native LMU geometry, depth reconstruction, motion vectors, temporal history, UI, post-processing and real eye-tracker latency remain separate research. Quad blending/guard bands are absent here and would add cost. No LMU FPS gain is claimed.
